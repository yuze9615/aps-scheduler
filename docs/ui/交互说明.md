# UI 交互说明（N3）

三张原型图：`主界面.svg` / `结果页.svg` / `风险页.svg`，统一视觉规范：

- **顶栏**：蓝色 `#1d4ed8` + 白字，全站一致。
- **卡片/面板**：白底圆角，浅灰边框；指标卡用浅蓝底 `#f0f4ff` + 蓝字。
- **按钮三态**：禁用（灰 `#9ca3af`）/ 可点（蓝 `#1d4ed8`）/ 进行中（蓝 + 旋转 spinner）。
- **语义色**：迟到红 `#b91c1c`、按期绿 `#166534`、待确认灰 `#6b7280`。

## 主界面（`主界面.svg`）
1. **空态**：未选择文件时，文件框显示"未选择文件"，「上传台账」「生成排产」均为禁用（灰）态。
2. **已上传态**：选中文件后框内显示已识别 sheet 与行数，两个按钮变蓝可点。
3. **错误态**：非 xlsx / 缺 sheet / 空表时，顶部出现红色 banner 中文提示（如"请先选择一个 .xlsx 台账文件"），**绝不白屏**；对应接口返回 400 中文错误。
4. **流程**：选文件 → ① 上传台账 → ② 生成排产 → 下方依次渲染指标卡 / 排单表 / 下载 / 风险 / 体检。

## 结果页（`结果页.svg`）
- 顶部**指标卡**：总工时跨度、迟到单数、工序任务数、可用设备。
- **周排单表**列名齐全：`机台 / 单号 / 工序 / 数量 / 开工 / 完工 / 工时(分)`，49 行可滚动。
- **下载产物**：排单表.xlsx / 甘特图.html（新窗口，单文件离线可开）/ 交期风险清单.md / 数据体检报告.md；中文文件名下载不乱码（`filename*=UTF-8''`）。
- 甘特图由后端 `report.write_gantt_html` 生成，行=机台、色块=工序任务，悬停看起止时间。

## 风险页（`风险页.svg`）
- 每条风险标注：`❌ 迟到 X 天` / `✅ 按期` / `⚠ 待确认（交期缺失）`。
- 底部汇总**迟到单数**（如 7 / 13）。
- 风险数据来自 `core/pipeline._build_risk`，与排单表同一份排程结果，保证一致。

## 真实可运行对照
上述原型均已由 `web/index.html` 实现并通过端到端测试（上传→生成→下载，生成耗时 2.1s ≤ 5s，详见 `docs/测试报告.md`）。
